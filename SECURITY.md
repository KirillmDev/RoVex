# Security reports

If a report would expose private information or describe a vulnerability, use [GitHub private vulnerability reporting](https://github.com/KirillmDev/RoVex/security/advisories/new) if the repository offers it. Otherwise, open an issue asking for a private reporting channel without including vulnerability details.

Include the affected version, impact, and steps to reproduce using a test account or synthetic data. Remove session cookies, authentication tokens, credentials, and private account data before sharing logs or screenshots.
